เมนูหลัก 5 กลุ่ม

โครงสร้างเนื้อหาหลักของเว็บไซต์มหาวิทยาลัย

1. เกี่ยวกับมหาวิทยาลัย

about.php

  • ประวัติและความเป็นมา
  • วิสัยทัศน์ พันธกิจ ค่านิยม
  • โครงสร้างองค์กร
  • ผู้บริหาร
  • แผนที่มหาวิทยาลัย / การเดินทาง
  • อาคารสำคัญ / ผังวิทยาเขต

2. หลักสูตร/การศึกษา

programs.php

  • ปริญญาตรี — 6 คณะ
  • ปริญญาโท-เอก
  • หลักสูตรระยะสั้น / Micro-credentials
  • คณะ / วิทยาลัย (12 หน่วย)
  • ปฏิทินการศึกษา 2569

3. การรับสมัครเข้าศึกษา

admission.php

  • TCAS / รอบรับสมัคร (รอบ 1-4)
  • โควตา / พื้นที่ / ความสามารถพิเศษ
  • ทุนการศึกษา
  • คู่มือการสมัคร (4 ขั้นตอน)
  • ปฏิทินรับสมัคร + ดาวน์โหลดประกาศ

4. ข่าวสารและกิจกรรม

news.php

  • ข่าวมหาวิทยาลัย
  • ข่าวคณะ
  • กิจกรรม / ปฏิทินกิจกรรม
  • ประกาศ (ทางการ)

ติดต่อ

  • ติดต่อเรา — ฟอร์ม + ที่อยู่ + แผนที่

5. ระบบสารสนเทศภายใน

intranet.php + login.php

  • ระบบทะเบียน
  • LMS / E-Learning (Moodle)
  • E-Office / E-Document
  • HR / ระบบบุคลากร
  • ห้องสมุด / Library
  • ชำระเงิน / ประเมินการสอน / Dashboard
  • เข้าสู่ระบบ (SSO)
  • IT Helpdesk

ข้อมูลทั่วไป / ท้ายเว็บ

  • แผนผังเว็บไซต์ (หน้านี้)
  • ที่อยู่มหาวิทยาลัย / เบอร์โทร / อีเมล
  • นโยบายความเป็นส่วนตัว (Privacy)
  • การเข้าถึง (Accessibility)
  • บุคลากร · นักศึกษา · ศิษย์เก่า
